# 当前项目行为

桌面原型默认进入基础 IM，使用单一应用侧边栏和外壳。新增应用统一登记在 `src/project/desktop-apps.ts`，切换应用时保留已打开页面的状态。
IM 支持按名称和最新消息搜索、全部／未读／提及筛选、会话切换及本地文本发送。各会话保留独立草稿，发送只清空当前草稿。整页刷新重置模拟数据。
返回工作台栏目后原型 iframe 保持挂载，保留未提交输入和画布状态。三种拼接范式在工作台独立运行，表单范式取消不写入，保存只更新当前示例。
桌面默认 1280×875、最小 1094×875；fit 只改变显示比例，不改变产品逻辑尺寸。移动产品画布尚未接入，移动分类组件仍可独立预览。
标注数组默认空，不从示例或文档自动生成业务标注。标注开关和抽屉是独立状态。
基础 IM 使用独立工作对话样例。转发邮件卡片和权限案例留在 teleMail 参考项目，母版没有业务模块或移动迁移仓储。

后续新增业务由用户确认后在此维护。母版导出时可以附带独立的 teleMail 参考压缩包，参考项目与当前项目的状态和路由隔离。

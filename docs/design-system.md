## 唯一数据源与层次

`src/design-system/tokens.json` → `npm run tokens:generate` → `src/styles/tokens.css` → Tailwind 主题 / ui 原子 → blocks → 页面。

颜色、全局排版及共享控件刻度只在 JSON 修改；生成 CSS 不手工改。页面可维护自身布局、列宽、气泡形状和内容密度，不另建品牌色或全局字号。新角色可以增加；改变冻结角色时更新 `baseline-v1.json` 并记录原因。历史取样文档不覆盖当前规则，原 v0.1 说明已归档至 `docs/design/design-system-v0.1-history.md`。

## 排版

正式字体 Poppins，400 / 500 / 600 本地加载，中文回退 Microsoft YaHei；邮件原文可保留自身排版。

| 角色 | 字号 / 行高 | 默认字重 | 用途 |
| --- | --- | --- | --- |
| title-1 | 28 / 36 | 600 | 工作台页面标题 |
| title-2 | 22 / 30 | 600 | 工作台区域标题 |
| section-title | 20 / 30 | 600 | 产品栏目标题 |
| editor | 16 / 26 | 400 | 写信正文输入 |
| body | 14 / 22 | 400 | 正文、表单与控件 |
| caption | 12 / 18 | 400 | 摘要、辅助说明、工具栏 |
| metadata | 11 / 16 | 400 | 时间与紧凑计数 |
| micro | 10 / 14 | 400 | 桌面小标记与紧凑摘要 |
| mail-time | 9 / 14 | 400 | 仅桌面邮件行日期 |

小于 12px 的角色仅用于已存在的桌面密集信息，不能扩散到通用表单、主要正文或移动端。邮件列表 16/17px 行高与聊天姓名 20px 行高保留场景别名；页面版式未冻结。字体角色默认行高不要求覆盖所有组合布局。头像字母、品牌字标、邮件原文不作为通用文本刻度。

Label 保留官方 `text-sm / font-medium / leading-none`。产品小标签在组合层覆盖，不回改通用原子。

## 间距、尺寸和圆角

基础间距 4px，主要布局节奏 8px；不是所有截图列宽与工具条高度都必须为 4 的倍数。

| 变体 | 尺寸 | 适用范围 |
| --- | --- | --- |
| mini | 24px | 紧凑图标按钮 |
| small | 28px | 小操作按钮 |
| compact | 32px | 默认桌面按钮、表单字段 |
| default | 36px | 较宽松控件与筛选 |
| mail search | 34px | 邮箱导航搜索 |
| search | 40px | 常规产品搜索 |

保留现有 Button `xs / sm / default / lg / icon-*` API，映射到尺寸源，不要求重写调用方。移动端 44px 热区仅为建议，不等于移动规范已验收。

头像：sm 24、ui 32、lg 40；邮件 30、聊天 46、资料 64 为业务变体。Avatar 根节点允许徽标超出图片轮廓，图片和 fallback 各自圆形裁切。

圆角刻度 2 / 4 / 8 / 12 / 16 / 20 / 24 / full。菜单、Popover 默认 16；密集邮件菜单通过 `radius-menu-compact` 使用 12；联系人摘要 20、资料卡 24。菜单项自身小圆角不跟随容器扩大。具体气泡形状和页面卡片仍可调整。

桌面画布默认 1280×875、最小 1094×875；与浏览器窗口独立、居中、可拖动和调整尺寸。小窗口由工作台外层滚动，不自动缩放产品。

## 交互状态、层级与动态

- 通用键盘焦点为深绿 2px，独立控件外描边；组合输入可由父容器 `focus-within` 表示。正文编辑区域使用内描边，不能移除焦点后不提供替代。
- disabled 默认透明度 0.5，不响应操作；未实现入口继续 disabled，不伪造真实业务反馈。复杂官方原子的内部选择与焦点结构保留，后续逐项验收，不能宣称全部状态已冻结。
- hover 以现有中性背景为基准；selected 使用对应角色，不能把 hover 当选中或未读状态。业务状态含义仍以已确认需求为准。
- Portal 层级：遮罩 40、Dialog / Sheet / Drawer 50、菜单 / Select / Popover / Hover Card / Combobox 60、Tooltip 70、Toast 80。组件内部徽标等局部层级不参与这个刻度。工作台和产品 iframe 仍是独立层叠上下文。
- 动态刻度 120 / 180ms；减少动态效果时通用过渡归零。复杂第三方动画未逐项冻结。

## 维护和验证

`npm run build` 校验变量生成同步、限定基础基线、组件用法、目录覆盖、必要账户工作流状态、TypeScript 和生产构建。`npm run design:check` 可单独检查冻结条目。新增组件文件和导出仍须补齐分类及预览。

基础规则调整需要同步变量源、生成 CSS、基线及变更说明，并由用户进行视觉验收。不得自动生成页面开发标注。新增业务流程继续先提供选项确认。
